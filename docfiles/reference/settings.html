Reference

Settings

The settings are on the Settings tab in the Thumbnailer window, and in Edit → Editor Preferences → Plugins → Thumbnailer. Both show the same settings.

The settings are saved per user and per project in Saved/Config/<Platform>Editor/EditorPerProjectUserSettings.ini, under [/Script/Thumbnailer.ThumbnailerSettings]. They are not shared through source control. The camera bookmarks and the default view are saved there too.

Camera​

SettingDefaultDescription
Camera TypePerspectivePerspective or Orthographic. See Camera and Framing.
Field of View (FOV)85The field of view of the perspective camera. A smaller value gives a flatter look. Only used with Perspective.

Output​

SettingDefaultDescription
Thumbnail Resolution512 x 512The width and height of the thumbnail. Also set under Output in the right panel.
File ExtensionPNGPNG or TGA. Also set under Output in the right panel.
Save DirThumbnailsThe folder in Content the thumbnails are imported to. Thumbnails is /Game/Thumbnails.
File PrefixThumb_Added before the asset name, for example Thumb_SM_Chair.
Override Thumbnail NameEmptyReplaces the asset name in the file name. Not saved, it is cleared when the editor restarts.
Transparent ThumbnailOffRemoves the background when capturing. See Transparent Thumbnails.
Hide Editor BillboardsOnHides the editor billboards (sprites) of an actor, for example the icons of lights and audio components.

An empty Save Dir or File Prefix is set back to its default.

Rendering​

These features are turned off while capturing, and most of them in the preview too. The console variables are changed only during the capture and are restored afterwards.

SettingDefaultDescription
Disable Anti AliasingOnTurns off anti-aliasing and temporal anti-aliasing.
Disable Auto ExposureOnTurns off auto exposure (r.DefaultFeature.AutoExposure).
Disable Motion BlurOnTurns off motion blur (r.DefaultFeature.MotionBlur, r.MotionBlurQuality).
Disable Screen Space ReflectionsOnTurns off screen space reflections (r.SSR.Quality). Also turns off screen space ambient occlusion in the preview.
Disable Eye AdaptionOffTurns off eye adaptation (r.EyeAdaptationQuality).

Viewport​

These settings only change the preview. Nothing here is part of the capture.

SettingDefaultDescription
Display Speed ControlsOnShows the camera speed controls in the lower left of the preview.
Display Camera ControlsOnShows the rotation arrows on the edges of the preview.
Show CrosshairOnShows a crosshair in the center of the preview.
Crosshair ColorBlackThe color of the crosshair.
Crosshair Size15The size of the crosshair in pixels.
Show FrameOnShows frame corners in the preview.
Frame ColorWhiteThe color of the frame corners.
Frame Size512The size of the frame in pixels. At least 50.
Draw GridOffDraws a grid in the preview scene.
Draw AxesOffDraws the world axes in the preview.

Workflow​

SettingDefaultDescription
Show NotificationsOnShows a notification with the name of each new thumbnail. Click the name to find it in the Content Browser.
Highlight ThumbnailsOffSelects each new thumbnail in the Content Browser.
Suppress Overwrite DialogOffOverwrites existing thumbnails without asking.

# Keyboard Shortcuts

The shortcuts work when the preview has keyboard focus. Click the preview first. The list is also shown in the window under the **?** button.

## Thumbnailer
| Shortcut | Action |
|---|---|
| `C` | Capture a thumbnail |
| `F` | Frame the current asset |
| `R` | Move the camera to the default view |
| `0`–`9` | Move the camera to a camera bookmark |
| `Ctrl` + `0`–`9` | Save the current view to a camera bookmark |

## Viewport controls
| Input | Action |
|---|---|
| Right mouse button + drag | Rotate the camera |
| Right mouse button + `W` `A` `S` `D` | Move and rotate the camera |
| Right mouse button + mouse wheel | Change the camera speed |
| `Alt` + left mouse button | Orbit around the asset |

The other editor viewport controls work too, for example `Q` and `E` to move down and up while holding the right mouse button.
